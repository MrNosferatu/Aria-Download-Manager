Aria Download Manager

The extension hands downloads to the local Aria Download Manager daemon. Start it first (run.sh or the systemd user unit), and register the IPC bridge once with python3 -m aria_download_manager --install-native-host.

Extension

Manager

The extension reaches the manager through its native-messaging helper and the manager's Unix socket — nothing goes over the network, so a VPN or proxy in the browser cannot get in the way.

What gets caught

A rule for example.com covers its subdomains, and matches both the page you are on and where the file comes from. The right-click menu still works on an excluded site.
