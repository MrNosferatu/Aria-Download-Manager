Browser extension

Load extension/ in Firefox (about:debugging → This Firefox → Load Temporary Add-on → pick manifest.json) or Chrome (chrome://extensions → Developer mode → Load unpacked). It takes over the browser's own downloads and forwards them here with the page's cookies, referer and user-agent, so login-protected files still work.

To keep it installed permanently in release Firefox the add-on has to be signed by Mozilla — extension/build.sh sign unlisted does that and hands back an .xpi you install from about:addons.
